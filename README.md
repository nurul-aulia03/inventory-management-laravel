# InventoryPro — Sistem Informasi Manajemen Inventaris

InventoryPro adalah aplikasi berbasis web menggunakan Laravel untuk membantu pengelolaan data inventaris.

## Fitur Utama

- **Dashboard:** Halaman utama sistem.
- **Manajemen Produk:** Mengelola data produk.
- **Manajemen Kategori:** Menambah, mengubah, dan menghapus kategori.
- **Manajemen Supplier:** Mengelola data pemasok.
- **Pergerakan Stok:** Mencatat barang masuk dan barang keluar.

## Teknologi

- PHP 8.3
- Laravel 13
- Blade
- HTML dan CSS
- MySQL/MariaDB
- Git dan GitHub

## Cara Menjalankan

1. Clone repository ini.
2. Jalankan `composer install`.
3. Salin `.env.example` menjadi `.env`.
4. Atur konfigurasi database pada `.env`.
5. Jalankan `php artisan key:generate`.
6. Jalankan `php artisan migrate`.
7. Jalankan `php artisan serve`.
